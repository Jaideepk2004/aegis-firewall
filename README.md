# AI Adaptive Firewall Dashboard

A real-time network intrusion detection system powered by three
reinforcement learning algorithms, served via a Flask dashboard.

---

## Three RL Algorithms Compared

```
┌─────────────────┬──────────────────┬─────────────────────────────────────────────┐
│  Algorithm      │  File            │  How it works                               │
├─────────────────┼──────────────────┼─────────────────────────────────────────────┤
│  Q-Learning     │  qlearning.py    │  Lookup TABLE of Q(state, action) values.   │
│                 │                  │  State must be DISCRETISED (rounded).        │
│                 │                  │  Cannot generalise to unseen states.         │
│                 │                  │  Good for: understanding RL fundamentals.    │
├─────────────────┼──────────────────┼─────────────────────────────────────────────┤
│  Deep Q-Network │  dqn.py          │  NEURAL NETWORK approximates Q(s,a).        │
│  (DQN)          │                  │  No discretisation needed.                   │
│                 │                  │  Uses Experience Replay + Target Network.    │
│                 │                  │  Good for: continuous state spaces.          │
├─────────────────┼──────────────────┼─────────────────────────────────────────────┤
│  PPO            │  train_ppo.py    │  Directly learns POLICY π(action|state).    │
│  (deployed)     │                  │  Outputs action probabilities, not Q-values. │
│                 │                  │  Clipped updates prevent unstable training.  │
│                 │                  │  BEST performance. Used in the dashboard.    │
└─────────────────┴──────────────────┴─────────────────────────────────────────────┘
```

### The RL Progression

```
Q-Learning  ──►  DQN  ──►  PPO
   (table)     (Q-net)   (policy)

Q-Learning: Q(s,a) stored in a dictionary
            Problem: 8 features × 10 bins = 10^8 possible states

DQN:        Q(s,a) = neural_network(s)[a]
            Fixes: continuous states, generalises to unseen inputs
            Extra: replay buffer + target network for stability

PPO:        π(a|s) = policy_network(s)   ← directly learns probabilities
            Fixes: no Q-values at all; on-policy; clipped updates
            Best: most stable, best accuracy, used for deployment
```

### Shared Environment: `env.py`

All three algorithms use the same `FirewallEnv`:

```
Observation : 8-feature packet vector  (float32, scaled [0,1])
Actions     : 0 = ALLOW | 1 = BLOCK | 2 = RATE-LIMIT
Rewards     : +2 correct block/allow | -3 false neg/pos | -1 rate-limit
```

## Setup & Training

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Download dataset + prepare train/test splits
python data_loader.py
# → downloads CIC-IDS2017 from Hugging Face
# → saves scaler.pkl

# 3a. (Optional) Run Q-Learning to understand the foundations
python qlearning.py
# → prints episode rewards, shows Q-table growing

# 3b. (Optional) Run DQN to see the neural-network approach
python dqn.py
# → trains a 8→128→64→3 network with replay buffer

# 4. Train the PPO model  (required for dashboard)
python train_ppo.py
# → trains for 200,000 timesteps (10 phases × 20K)
# → saves adaptive_firewall_ppo.zip + reward_log.npy

# 5. (Optional) Evaluate on test set
python test.py
# → prints accuracy, AUC, confusion matrix

# 6. Launch dashboard
python app.py
# → http://localhost:5000
```

## Algorithm Deep Dive

### Q-Learning (qlearning.py)

The Bellman update equation:

```
Q(s,a) ← Q(s,a) + α [ r + γ · max_a' Q(s',a')  -  Q(s,a) ]
                       └────────────────────────┘
                            TD Target
```

- `α` = learning rate (0.1)
- `γ` = discount factor (0.9)
- Epsilon-greedy: ε starts at 1.0, decays to 0.05

### DQN (dqn.py)

Same Bellman equation, but `Q(s,a)` is a neural network:

```
Input:  8 floats (packet features)
Hidden: 128 → 64 (ReLU)
Output: 3 floats (Q-value per action)

Loss = MSE( Q_online(s,a),  r + γ · max_a' Q_target(s',a') )
```

Key extras vs Q-Learning:
- **Replay buffer** (10,000 transitions) — random mini-batch sampling
- **Target network** — frozen copy updated every 500 steps

### PPO (train_ppo.py)

Policy gradient — directly learns π(a|s):

```
L_CLIP = E[ min( ratio · A,  clip(ratio, 1-ε, 1+ε) · A ) ]

ratio = π_new(a|s) / π_old(a|s)   (how much has policy changed?)
A     = advantage = Q(s,a) - V(s)  (how much better is a than average?)
```

The clip prevents the policy from changing too drastically in one update.
