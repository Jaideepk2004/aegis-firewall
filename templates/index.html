Three RL algorithms, one adaptive firewall

[ 1.0 ]

Q-Learning
Algorithm

Tabular reinforcement learning using a Q-table and Bellman updates. The foundation of the AI Adaptive Firewall — epsilon-greedy exploration teaches the agent to ALLOW or BLOCK packets step by step.
[ 2.0 ]

Deep Q-Network (DQN)

A neural network replaces the Q-table — 8 inputs → 128 → 64 → 3 actions. Experience replay and a frozen target network make training stable on continuous network-flow features.
[ 3.0 ]

PPO Policy
Gradient

Proximal Policy Optimization directly learns action probabilities π(a|s). Clipped updates prevent unstable training — the deployed production model powering the live dashboard.
[ 4.0 ]

Live Dashboard

Upload any network CSV and watch the PPO model classify each packet — ALLOW, BLOCK, or RATE-LIMIT — in real time via a streaming Flask dashboard with analytics and confusion matrix.
[ 5.0 ]

CIC-IDS2017
Dataset

Trained on real-world network intrusion data from Hugging Face — 50,000 flows, 8 packet features, 70/30 stratified split — with MinMax scaling and zero data leakage.

The AI Adaptive Firewall continuously monitors incoming network flows, enriches each packet with 8 handcrafted features, and lets the trained PPO agent decide in milliseconds — ALLOW, BLOCK, or RATE-LIMIT — with full analytics and model intelligence on every decision.

We built an AI-powered intrusion detection system

The AI Adaptive Firewall is a research-grade adaptive firewall that pits three reinforcement learning algorithms — Q-Learning, DQN, and PPO — against real network intrusion data, giving you a transparent view of how each model learns to protect your infrastructure.

[ 01 ]

Trained on real data

Built on the CIC-IDS2017 benchmark dataset — 50,000 real network flows spanning benign traffic and 14 attack types including DDoS, port scans, and web attacks, downloaded directly from Hugging Face.

[ 02 ]

Three algorithms, one environment

Q-Learning, DQN, and PPO all share the same FirewallEnv — making results directly comparable. Watch each algorithm improve episode by episode as epsilon decays and the policy converges toward optimal packet decisions.

[ 03 ]

Production-ready pipeline

From raw CSV upload to live streaming predictions — the trained PPO model runs deterministically on every row, reporting accuracy, ROC-AUC, confusion matrix, and action distribution in the Intelligence dashboard.
